# HCM Lite

## Stack
Node + Express + MongoDB · React + Vite + Tailwind · JWT · LLM tool calling

## Run

1. Clone the repository and navigate to the project directory.
2. Install dependencies for both the backend and the frontend (`web` directory):
   ```bash
   npm install
